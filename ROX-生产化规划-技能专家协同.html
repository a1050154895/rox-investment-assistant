ROX 投资助手 · 生产化规划

技能 × 专家协同路线图 ｜ 现状 v3.2.0 ｜ 编制于 2026-08-02 ｜ 定位：投资认知系统（决策日志本，非信号生成器）
结论先行：ROX 已是"可信数据 + 安全基线 + 宏观矩阵 + 334 纪律"的可演示 MVP，但 AI 助手、数据库、多用户、回测、会员 五项仍为空壳或缺失，不具备公开提供真实研判或收费的资格。下一步应以 PostgreSQL 持久化 + 多用户认证 + AI 后端 为 P0 地基，再调用 westock-data / westock-tool / news-search / wb-finance-skill 四大技能与 策略回测 / 量化研判 / 数据 三类专家，分阶段补完数据、研判、验证与风控能力。

一、现状评估（v3.2.0）

✓ 已落地（真实可用）

  • 战略文房 UI（桌面 + 移动端单列自适应）
  • 可信宏观矩阵：AKShare 6 指标 + 覆盖率门槛 + 确定性公式
  • 334 仓位纪律工作台：确定性规则引擎 + 前端 localStorage 配置
  • 宏观资讯 / 政策研判层（intelligence，AKShare 抓取 + 降级）
  • 决策日志 CRUD（内存态，未持久化）
  • 个股透视：K 线 / 资金流 / 框架一致性评分（AKShare + NeoData 快照）
  • 认知框架 L1–L5（卢麒元方法论结构化）
  • 安全基线：CSP / 请求 ID / 生产 CORS / /ready

✗ 空壳 / 缺失

  • AI 助手：纯前端输入框，后端 ai_api_key 被跳过，无模型接入
  • 数据库：PostgreSQL 未接入，/ready → database: not_configured，日志/设置仅内存
  • 多用户：无认证与账号隔离，localStorage 无法跨设备
  • 回测 / 框架验证：无引擎，无法验证方法论历史表现
  • 会员体系：硬编码假数据，无真实付费/权益
  • 实时行情稳定性：AKShare 冷启动慢、沙箱受限，依赖 NeoData 快照兜底
  • 选股 / 筛选：尚无论证层，仅静态自选股池

四、三阶段路线图

P0 · 生产化地基

可信 + 安全 + 可规模化
  • PostgreSQL 持久化（决策日志 / 334 配置 / 用户）
  • 多用户认证（JWT，账号级隔离）
  • AI 助手后端（LLM 接入：解释 / 复盘 / 追问）
  • 安全合规基线（合规材料、数据许可确认）

技能/专家：高级开发工程师 全栈；LLM API

验收：/ready → database: configured；多用户隔离通过；AI 可对话且只读风控。

风险：AKShare 商业许可；LLM 调用成本与延迟。

P1 · 核心能力补完

数据 × 研判 × 验证
  • 实时行情升级：westock-data + neodata 替代 / 补充 AKShare
  • 选股模块：westock-tool（filter/strategy/label/event/ranking）
  • 资讯研判：news-search 接入真实资讯库
  • 宏观矩阵增强：macro-transmission 方法论
  • 回测 / 框架验证：策略回测专家 + systematic-strategies

验收：选股页可用；资讯页真实数据；回测页输出历史框架一致性。

风险：数据源稳定性；回测不代表未来收益。

P2 · 上市级打磨

风控 × 会员 × 体验
  • 风控压力测试：risk-stress（VaR / CVaR / 蒙特卡洛）
  • 组合优化：portfolio-optimization
  • 会员 / 付费：真实权益（替换假数据）+ 支付
  • 移动端 PWA + 离线 + 推送告警
  • 结构化监控告警 + WCAG 2.1 AA

验收：压力测试页；会员真实；PWA 可安装；监控告警可用。

风险：金融合规审查；性能与冷启动。

五、执行时间线（建议节奏）

第 1–2 周 · P0

数据库 schema + 认证 + AI 后端骨架；/ready 转为 ok。主理人主导。

第 3–5 周 · P1

数据专家接入 westock-data/neodata；量化专家落地选股/资讯/宏观增强；策略回测专家交付框架验证页。

第 6–8 周 · P2

风控压测 + 组合优化 + 真实会员 + PWA；邀请内测 → 正式发布。

产品定位重申（来自 2026-07-29 重定位分析）：ROX 是"投资认知系统 / 决策日志本"，不是量化交易信号生成器。删掉"95% 准确率"目标；技术分析权重降至 5%；回测与 AI 仅用于记录认知过程、校准框架、沉淀经验，不直接给买卖信号。所有对外数据须标注来源 + 时点，资讯忠实原文，研判须 ≥2 项交叉验证。
