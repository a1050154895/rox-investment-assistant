## 使用边界（GLOBAL BOUNDARY）

- 这是**认知工具**而非交易终端：帮助思考，不替他思考。
- 所有「阶段 / 矛盾 / 评分」都是**研究代理**，不是精确概率，也不构成投资建议。
- 数据缺失时输出「未评估 / 待真实数据验证」，**禁止用静态分数或随机值补位**。

## L1 宏观定调

**核心方法**：主权信用 × 价值实现矩阵（3×3）。

- **R（原理论据）**：财政信用条件与价值实现条件，思想来源登记见 `docs/strategy_origins.md`。
- **I（复述）**：宏观判断从两个维度交叉，映射到矩阵后决定仓位基准。
- **A1（案例）**：扩张信用 × 高价值实现 → 核心池可提至 35%；收缩信用 × 低价值实现 → 卫星池减至 15%、现金提至 55%。
- **A2（触发）**：开盘/复盘前需要确定仓位基准，或宏观数据更新时。
- **E（执行）**：读真实宏观指标 → 映射矩阵 → 定基准；数据缺失输出「未评估」。
- **B（边界）**：矩阵是研究代理而非主权信用评级；指标缺失不得用静态分数或随机值替代。

## L2 资本周期

**核心方法**：积累 → 集中 → 流转 → 分配 → 再生产，五阶段各有可观测盘面特征。

- **R**：资本运动的社会再生产抽象，见 `docs/strategy_origins.md`。
- **I**：每阶段用「成交额、龙头集中度、北向资金、政策导向」四项特征定位。
- **A1**：集中阶段 = 成交额显著放大 + 龙头集中 + 大幅净流入；分配阶段 = 量能衰减 + 高位股回调 + 净流出。
- **A2（触发）**：需要判断当前市场所处周期阶段以决定仓位/策略时。
- **E（执行）**：观测四项特征 → 比对五阶段表 → 定位；阶段不清输出「建议观望」。
- **B（边界）**：缺少可靠成交结构、资金流和宏观数据时不判断阶段；现实可能跨越或反复，不是机械钟摆。

## L3 矛盾分析

**核心方法**：识别量价 / 资金 / 结构 / 预期四类核心矛盾的主要方面。

- **R**：主要矛盾/次要矛盾与矛盾转化，见 `docs/strategy_origins.md`。
- **I**：四类矛盾分别量化强度，排序选出主要 / 次要 / 第三矛盾。
- **A1**：放量下跌 = 主力出货（量价矛盾）；北向与主力流向分歧（资金矛盾）。
- **A2（触发）**：复盘或调仓时需要识别当前主要矛盾时。
- **E（执行）**：算四类强度 → 排序 → 强度 >70 标注强矛盾并跟踪转化。
- **B（边界）**：矛盾强度是研究代理而非概率；数据不足诚实降级，绝不编造矛盾。

## L4 334 纪律

**核心方法**：核心 30% / 卫星 30% / 现金 40%；建仓按首仓 30% → 确认仓 30% → 主升仓 40%。

- **R**：风险约束与分批进场的纪律原则。
- **I**：用三段建仓节奏替代一次性满仓，用三池分离不同风险属性资金。
- **A1**：首仓只在趋势结构初步出现时 ≤30%；确认仓需量能+基本面+政策至少 2 项确认。
- **A2（触发）**：任何建仓/加仓/减仓动作执行前。
- **E（执行）**：确认三池比例 → 分批进场 → 破位信号按反向顺序减仓。
- **B（边界）**：任意一段未触发，后续段不能启动；纪律是风险约束，不保证收益。

## L5 一致性评分

**核心方法**：矛盾 30% + 价值 35% + 宏观 25% + 技术 5% + 纪律 5%。

- **R**：用「决策与框架的一致性」替代「预测涨跌」作为复盘尺度。
- **I**：五维加权，总分 ≥75 高一致、45-74 中等、<45 低一致。
- **A1**：深度低估 + 买入 = 高分；高估 + 买入 = 低分。
- **A2（触发）**：记录投资决策或复盘时。
- **E（执行）**：加权求和 → 判定一致性等级 → 低一致性（<60）暂停复核。
- **B（边界）**：评分衡量「一致性」而非「盈亏」；技术分析权重仅 5%，不得反客为主。

## 外来方法蒸馏：多周期趋势状态与建仓节奏（2026-09 登记）

> 来源：2026-07-11 第三方公开讲座《投资的中庸之道》（思想来源登记见 strategy_origins.md）。
> 只蒸馏抽象方法，不取任何标的判断与时点结论；下述内容是研究参考框架，不是交易信号。

### 多周期趋势状态确认（MACD 矩阵）

- **R**：用同一指标（MACD 12/26/9）在多个周期上分别描述趋势状态，避免用单一周期做全部决策。
- **I**：年/季看方向，月看阶段，周/日看节奏；每周期独立输出 DIF/DEA 相对位置与最近一次交叉。
- **A1**：个股页「多周期 MACD 状态」卡（确定性计算，数据可溯源到真实 K 线）。
- **A2（触发）**：个股研究、建仓前检查、持仓复核。
- **E（执行）**：高周期定方向 → 低周期找时机 → 状态写入研究卡作为证据（事实层，不是结论）。
- **B（边界）**：指标只描述历史状态，不预测未来；周期间矛盾（如月多日空）时以高周期为方向、低周期为时机参考；年线级样本不足时系统如实标注不可用。

### 建仓节奏与成本压降（"庸"）

- **R**：用分批进出场把"择时错误"的代价摊薄，并把振荡期的操作转化为持仓成本的下降。
- **I**：ROX 334 纪律已含「三段建仓 30/30/40」；本方法为其触发条件提供一个具体化参考——首仓在方向确认后、确认仓在次级状态转多时、离场在状态转空或动能收缩时，叠加分红对成本的实质性降低。
- **A1**：建仓前在研究卡写明各段触发条件；每笔操作进决策日志；持仓成本 =（Σ买入 − Σ卖出 − 分红）/ 当前股数。
- **A2（触发）**：建仓、加减仓、复核持仓成本。
- **E（执行）**：按预设触发执行 → 每次操作后重算持仓成本 → 与纪律检查（334 工作台）交叉验证。
- **B（边界）**：节奏框架不构成信号；机械执行有风险，任何一段未触发后续段不启动；压降成本不改变标的基本面判断的独立性。

### 执两用中：不摸顶、不抠底

- **R**：放弃在极值点进出的执念，只取趋势的中间段。
- **I**：进入位置不追求最低点，退出不追求最高点；腰部进入 + 状态确认退出即可接受。
- **A1**：研究卡里写明"我取哪一段"，而不是"我猜顶底在哪"。
- **B（边界）**：错过极端行情是该方法主动承担的成本，不是失误。

### 最坏情况先行

- **R**：入场前先书面确认可承受的最坏结果，再谈收益。
- **I**：最大可接受回撤、最长可接受不涨期、仓位上限，三者写入研究卡失效条件。
- **B（边界）**：接受最坏结果不等于放任风险，仍受 334 纪律硬约束。
