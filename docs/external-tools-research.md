# 外部工具研究登记

> 本文用于诚实登记我们研究过的外部金融工具，明确“可以借鉴什么”“为什么暂不整套引入”。任何被纳入 ROX 的思路都必须保留 ROX 的可信数据边界：数字由确定性代码计算，叙述才交给 AI；无法取到的数据一律标注不可用，不伪造。

## FinRobot（AI4Finance Foundation）

仓库：https://github.com/ai4finance-foundation/finrobot

**最有价值的原则**

- 多智能体股票研究流水线：Lead Agent → 数据 → 分析 → 建模 → 综合 → 报告，再配多空双方辩论与裁判。
- **确定性计算与 LLM 叙述分离**：DCF、DDM、LBO、WACC、同业比较、蒙特卡洛全部由 Python 代码计算，LLM 只负责推理、综合和写报告，并保留数值来源。
- 13 章节研究报告、IC 备忘、证据链接与数字溯源。

**对 ROX 的借鉴**

- 继续把“指标可计算、结论可溯源”作为硬约束，不因引入 AI 而破坏。
- 未来若做单标的深度研究页，可参考“数据 → 建模 → 多空辩论 → 报告”的结构，但 ROX 只落成研究卡扩展，不整套搬入 18 万行代码。
- 可借鉴多空辩论：在反模式自查之外增加一个“多空立场互搏”的提示模板。

**暂不引入**

- 依赖 FMP / Finnhub / yfinance / SEC EDGAR 等多套国外数据源，ROX 当前主战场是 A 股与场内基金。
- 重型 Agent 编排与 Tauri 桌面壳，超出当前部署规模。

## TradingAgents-CN（hsliuping）

仓库：https://github.com/hsliuping/TradingAgents-CN

**它是什么**

- 面向中文用户的多智能体交易研究平台，基于 TauricResearch/TradingAgents，采用 FastAPI + Vue3 + MongoDB + Redis。
- 提供分析师、研究员、交易员等多角色辩论，以及股票/行业/宏观分析、策略回测、知识图谱等学习能力。

**判断**

- 项目明确采用“混合许可证”：`app/` 与 `frontend/` 为专有部分，商业使用需要授权；个人使用开源。
- 它依赖 MongoDB、Redis、Tushare、多模型，工程规模与 ROX 差异很大。

**对 ROX 的借鉴（仅思想层面）**

- 多角色辩论（分析师 vs 风控 vs 交易员）可以作为研究卡里的一组提示词与证据模板，不复制其代码。
- 中文模型 Provider 兼容思路值得参考，但 ROX 的 AI 辅助模块已支持多 Provider，不重复建设。

**暂不引入**

- 不复制受授权限制的后端与前端代码。
- 不引入 MongoDB / Redis 作为 ROX 的运行时依赖。

## GitHub topic：financial-analysis

这个主题下汇集了大量仓库，最有代表性的是：

- `ai-berkshire`：基于 Claude Code / Codex 的价值投资研究框架，多 Agent 对抗式分析。
- `PyPortfolioOpt`：组合优化、Black-Litterman、分层风险平价。
- `FinanceToolkit`：透明可扩展的财务分析工具。
- `QuantResearch`：量化策略与回测。

**对 ROX 的借鉴**

- 组合优化与风险平价属于“确定性计算”，未来可作为组合页的数值模块，但必须先有真实持仓与净值的可靠输入。
- 多 Agent 对抗式研究可借鉴其“找反证”的思路，ROX 已用反模式自查与反证字段实现类似能力。

**暂不引入**

- 大多依赖海外数据源或美股场景，与 ROX 当前 A 股定位不匹配。
- 大量仓库长期未维护，不宜直接引入作为核心依赖。

## financial_research_report（li-xiu-qi）

仓库：https://github.com/li-xiu-qi/financial_research_report

**它是什么**

- 基于 LLM 的金融研报自动生成系统：多源数据采集 → AI 财务分析 → 可视化 → 完整研报输出，包含行业与宏观研究工作流。

**对 ROX 的借鉴**

- 研报结构化（基础研报 → 整合研报 → 深度研报）与 ROX 研究卡“证据 → 假设 → 反证 → 决策”的路径互补。
- 财务数据采集思路可参考，但必须接入 ROX 已信任的数据源，不能仅凭 AI 生成结论。

**暂不引入**

- 它依赖 OpenAI 兼容 LLM 生成大量文字，ROX 默认不依赖 LLM，确保无 AI 模式仍完整可用。
- 输出含“投资建议”，ROX 明确不做自动荐股。

## Finance AI LLM（leecyno1）

仓库：https://github.com/leecyno1/finance-ai-llm

**它是什么**

- 实时财经快讯 + 宏观数据 + 可配置大模型问答的 Web 应用，带新闻聚合、去重、排序、SearXNG 检索与可观测性契约。

**对 ROX 的借鉴**

- 新闻聚合的可观测性契约（成功/失败/熔断分类）与 ROX 数据源健康面板思路一致。
- 缓存命中率、慢重算 Top、阈值告警这类运维指标，适合 ROX 后续给数据源健康页增加更细的观测字段。
- 财经快讯多源对比可作为 ROX 情报页“同一事件多来源”的改进方向。

**暂不引入**

- 它依赖 Next.js、LangChain、SearXNG 与 Docker，与 ROX 当前单页应用 + FastAPI 的轻量架构不同。

## DeepEar（HKUSTDial）

仓库：https://github.com/HKUSTDial/DeepEar

**它是什么**

- 把公开观点整理成投资逻辑链的 Deep Research 框架，用多智能体（趋势、财务、预测、报告）把资讯转成信号与报告。

**对 ROX 的借鉴**

- 已落地：把“资讯/价格/判断持续演化”的思想融入异动雷达，显示最大量价时间、方向代理、速度与新闻匹配状态。

**暂不引入**

- 其 Kronos 新闻投影预测模型、多 Agent 编排与大量外部资讯源，需要高额部署与数据成本，ROX 不引入未经验证的预测分数。

## 结论

这些项目都值得研究，但不等于都要搬进 ROX。ROX 的差异化价值是“可验证、可复盘、可溯源”，任何外部工具如果破坏这一边界，即使功能看起来更强大，也不应该直接引入。建议优先级：

1. 先做强 ROX 已有的事件研究闭环（异动时间点、新闻时间关系、量价方向、事件持续性）。
2. 再把确定性计算扩展（组合优化、风险平价、实质利率口径校验），全部保留数据来源。
3. 最后才考虑 AI 驱动的多智能体报告生成，且必须叠加明确的来源、时间与不可用标注。
