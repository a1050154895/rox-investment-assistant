# 思想来源登记（strategy_origins）

本项目的方法论表达均为**项目原创**，不包含任何第三方原文段落。
下面对思想来源做诚实登记，明确「借鉴了谁的思想」与「本项目如何改写」。

## 登记原则

- 不逐字引用任何受版权保护的原著/讲座原文。
- 只提炼「公有领域理论」与「公开讲座思想的抽象框架」，再以项目自己的语言重述。
- 所有投资结论均标注为研究代理，不构成投资建议。

## 本项目不做什么

- 不声称得到任何来源方的授权或背书。
- 不把「思想来源」包装成「可验证事实」；方法是否有效需用户自行回测与复盘。
- 不因思想来源而放松数据可信度纪律：没有真实数据时仍输出「未评估」。
